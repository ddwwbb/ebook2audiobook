# Audiobook Studio 实施计划（已全部确认）

## TTS 引擎清单（13 种，全部确认）
- 云端：Edge TTS、阿里 CosyVoice、火山豆包、小米 MiMo
- 本地：CosyVoice 2、GPT-SoVITS V4、IndexTTS 2、Fish Speech、F5-TTS、ChatTTS
- sherpa-onnx：VITS（中文多 speaker）、Kokoro

## 技术栈
- 后端：Python FastAPI（REST + WebSocket）
- 前端：React + TypeScript SPA（Vite）
- 桌面：Tauri 2（Mac/Win/Linux x64+arm64）
- 无桌面：Docker + 浏览器（RK3588 定位云端客户端）
- LLM：OpenAI 兼容 + Anthropic 双协议
- 与 ebook2audiobook 解耦：只用其 EPUB 解析+拼接+M4B 导出
